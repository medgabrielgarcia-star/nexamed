# Alcance de la alfa (MVP)

La visión completa se ve como estructura del sitio, pero solo algunas piezas funcionan de verdad.

## Qué funciona

| Sección | Alcance |
|---|---|
| Artículos | 1 artículo de hipertensión, con referencias y fecha de revisión |
| Diccionario | Búsqueda con unos 20 términos reales, en un archivo JSON |
| Herramientas | Calculadora de IMC (portada desde `calculadora-imc`, con correcciones) |
| Referencias y fuentes | Sección visible, ligada a cada contenido |
| Cursos | Página del curso de hipertensión con lista de interés |

## Qué solo se ve como estructura

- Infografías, videos y cómics: página con espacio reservado y mensaje "próximamente".

## Fuera de alcance (fases posteriores)

- Cuentas de usuario
- Pagos
- Base de datos
- Panel de administración
- IA
- Sistema completo de cursos

## Reglas

- No se afirma en la web ningún contenido o cifra que aún no exista.
- Cada contenido indica fecha de revisión y de próxima actualización.
- La educación general se diferencia siempre del diagnóstico o tratamiento individual.
- Las herramientas son orientativas, no instrumentos diagnósticos validados.
- No se recopilan datos médicos personales.
